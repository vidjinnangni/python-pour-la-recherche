# Module 00 : Prise en main

## Objectifs

À la fin de ce module, vous saurez :

- choisir et installer un environnement pour coder en Python (local ou dans le cloud) ;
- ouvrir et exécuter un notebook Jupyter ;
- comprendre les bases de Git/GitHub pour naviguer dans ce repo et récupérer les mises à jour ;
- vous repérer dans la structure de ces ressources.

## Prérequis

*Aucun*. C'est le point de départ !

## Durée estimée

1 à 2 heures.

## Contenu du module

1. **Choisir son environnement**
    - Option 1 : Google Colab (recommandé, si vous débutez)
    - Option 2 : Installation locale (Python + JupyterLab) sur votre ordinateur, via `venv` ou `conda`

2. **Se repérer dans Jupyter**
    - Cellules de code vs cellules de texte (Markdown)
    - Exécuter une cellule, l'ordre d'exécution
    - Raccourcis utiles

3. **Notions de base sur Git et GitHub**
    - Cloner un repo
    - Récupérer les mises à jour du cours

4. **Se repérer dans ce repo :** Où sont les modules, les exercices, les corrigés, les jeux de données ?

## Pour commencer

Ouvrez le notebook [`00-prise-en-main.ipynb`](00-prise-en-main.ipynb) de ce module.

Si vous utilisez Google Colab, vous pouvez l'ouvrir directement en important le fichier `.ipynb` depuis GitHub dans l'interface Colab (Importer le notebook → GitHub).

## Exercices

Voir le dossier [`exercices/`](exercices/). Ce module contient un seul petit exercice de vérification d'environnement (exécuter une cellule, importer une bibliothèque, afficher un résultat).
